BMANGA V6

- Khi đọc truyện: header Bmanga phía trên giữ như trang bình thường.
- Không có thanh điều hướng chương cố định phía trên.
- Chỉ có một thanh điều hướng chương cố định ở dưới.
- Thanh dưới gồm: Trang chủ, Quay lại, Chương trước, Chọn chương, Chương sau, Theo dõi.
- Admin có thêm Backup JSON và Restore JSON.
- Restore JSON tạo/cập nhật lại truyện và chương từ file backup.
- Restore không xóa tài khoản người dùng.

Cách cập nhật:
1. Giải nén.
2. Ghi đè source hiện tại.
3. Commit & Push GitHub.
4. Render deploy lại.
5. Refresh trang trên điện thoại.
